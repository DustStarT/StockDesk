数据源管理
行情由统一 Provider Hub 调度：优先使用批量请求，并在健康数据源间轮换；遇到 403/429/WAF 类响应会自动熔断冷却。该机制用于降低单源负载与合规故障回退，不用于绕过访问控制。
内置公开数据源
自定义 / 付费 REST 数据源（高级）
可添加 quote / kline / minute 的 GET/POST REST 映射；不执行用户 JavaScript。URL/Headers/Body 可使用 {code}、{symbol}、{market}、{secid}、{period}、{count}、{symbols}、{codes}、{secret} 占位符。报价接口支持 batch:true，一次发送整个股票池。密钥单独使用系统安全存储保存。
