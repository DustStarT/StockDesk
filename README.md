## 这是一个简单的股票分析系统

> 输入一个股票代码。它从**多个免费数据源**拉行情与基本面，算出 **22 类技术指标**并按指标族去重复计票，给出**短期 / 中期 / 长期三个独立周期**的量化信号，回溯**历史上出现同样信号时的胜率**；接着可以跑**策略回测**（含样本外保留检验与参数邻域稳健性），把结论加入**后台监控**等提醒；最后可以让 **LLM 联网自主研究**一轮，输出可导出 Word / PDF 的中文研报。

全程**免费数据源、零 API Key 即可跑通**。LLM 与本地 AI 都是**可选增强**。

## 📊 功能详解

### 盯盘与行情

- 自选股**分组**管理，实时行情列表，可直接为个股设置买入 / 卖出目标价；
- 日 K / 周 K / 月 K **前复权** + **分时**图；
- 拖动分隔条自由调整布局，比例本机保存，双击复位；
- 图表**滚轮缩放、拖动平移**；技术副图与主图时间范围联动；
- 顶部市场状态（连接中 / 交易中 / 休市）、`🔔` 提醒中心、`🌙` 主题、`🤖` AI 设置；
- 毛玻璃透明度、刷新间隔（2–60 秒）可调；
- 关闭按钮可最小化到托盘；**窗口隐藏时只暂停界面刷新，后台监控继续跑**。

### 量化信号 · 多周期

「信号」面板不是简单罗列指标数值，而是分层的：

```text
市场状态            →  指数合成强度 / 市场风险 / 多空家数
基础因子综合方向     →  偏多 / 中性 / 偏空（多空阈值统一 ±25，非当日涨跌）
短 / 中 / 长期趋势   →  5–10 / 20–60 / 60–120 交易日，各自独立计算
基础因子族          →  趋势 / 动量 / 量价 / 情绪 / 波动 / 支撑压力 / 成本
22 类扩展指标聚合    →  按族去重复计票后的方向分 + 过热波动风险
历史信号验证        →  历史上出现相似信号后 1 / 5 / 20 日的胜率与均值
当前事件            →  公告、新闻等结构化事件
分时择时            →  按分钟增量成交量计算的 VWAP 关系
```

面板里明确写着这句话，也是这个模块的设计原则：

> 长中短期独立计算，**不是未来涨跌预测**。历史统计只描述样本内表现，不代表未来收益。

样本不足时它会直接显示「样本不足/待验证」。日 K 尚未收盘时会提示「日 K 未包含今日时，趋势仅代表历史数据」。

### 22 类参数化技术指标

```text
MACD   DMI   DMA   FSL   TRIX   BRAR   CR    VR    OBV   ASI   EMV
VOL-TDX  RSI   WR    SAR   KDJ   CCI    ROC   MIKE  BOLL  PSY   MCST
```

- 每类指标有**独立超参数**（周期、均线、信号线…），全部可持久化；
- 支持 **1 / 2 / 3 屏**副图自由组合；
- 归入 **7 个因子族**：`趋势 / 动量 / 量价 / 情绪 / 波动 / 支撑压力 / 成本`；
- 改参数会**同时影响**副图计算、扩展指标评分、综合研报，以及发送给 LLM 的技术证据。

### 选股

- 从行业板块出发筛选全市场成分股，支持三种口径：

| 口径 | 计算方式 | 适合 |
|:--|:--|:--|
| 技术 | 技术因子综合评分 | 找形态 |
| 价值 | 估值 / 基本面评分 | 找便宜 |
| 混合 | 技术 ×0.6 + 价值 ×0.4 | 默认 |

- 行业**搜索框**（名称或板块代码模糊匹配，回车直接跑首个匹配项）；
- 结果**二次搜索**（股票名称 / 6 位代码 / `sh`/`sz` 前缀）；
- 最大结果留空或填 `0` = **返回全部**（单行业安全上限 500）；
- 每页 10/20/50/100 条，支持首 / 上 / 下 / 末页；
- 切换面板再回来，**保留**行业、搜索条件、结果与分页位置。

### 策略实验室

内置 4 类规则，**默认走「智能推荐」**：

| 预设 | 思路 |
|:--|:--|
| **趋势突破** | 趋势已形成，接近/突破 20 日高点且量能确认时介入 |
| **趋势回踩** | 保持中期多头，只在回到 MA20 附近、风险不过热时介入 |
| **动量强化** | 偏重 20/60 日动量与量价共振，容忍更高波动 |
| **稳健趋势** | 提高趋势门槛、压低允许风险，信号更少，偏向控制回撤 |

智能推荐会：

1. 依据历史信号分布、近期 ATR / 波动率、风险分布与当前市场 Regime 构造**数据自适应参数**；
2. 在历史**前段选参 / 中段验证**，不直接挑「全历史收益最高」的那组；
3. 把最后约 **20% 历史作为独立保留检验**，并额外做滚动区间检查；
4. 做 **27 组邻近参数扫描**，评估参数的**邻域稳健性**（而不只是最优点表现）；
5. 输出 `稳健 / 均衡 / 积极` 三档建议，并给出策略适配度、历史可靠度、参数稳定度、市场匹配度、样本充分度。

回测按**次日开盘成交**，计入手续费与滑点；指标含收益、超额收益、最大回撤、胜率、Sharpe、盈亏比与分段验证、交易明细。

> 当交易样本过少、保留段没有足够交易、严重跑输买入持有，或参数邻域脆弱时，推荐器会**主动降级为「样本不足 / 当前不优先」**。

「手动高级」保留全部原始参数，可从推荐结果一键切过去微调。

### 策略监控与提醒

把当前策略快照**一键加入后台监控**，配置独立保存：

```text
观察中 → 接近买点 → 待分时确认 → 正式买点
                                    ↓
                             模拟/实际持仓
                                    ↓
                        风险预警 → 退出触发
```

- 入场完成度默认 **80%** 提醒「接近买点」；正式买点可要求**分时 VWAP / 走势确认**；
- 买点后可进入明确标注的**模拟跟踪**，也可手动录入真实成本与买入日期；
- 持仓监控：固定止损、移动止损、止盈、最长持有期、因子转弱、风险阈值；
- `🔔` **提醒中心**汇总全部监控标的、当前阶段与最近提醒；
- 通知**带去重与冷却**（可选 5–120 分钟），默认**只在 A 股常规交易时段**弹系统通知；
- 监控间隔独立于行情刷新间隔（10–60 秒可选）。

配置与历史分别落在 `~/.stockdesk/strategy-monitors.json` 与 `monitor-alerts.json`。**监控只提醒，不会自动下单。**

### 综合研报与 LLM

支持 **OpenAI / DeepSeek / Anthropic Claude / Google Gemini**，以及任何 **OpenAI-compatible** 自定义服务。（当前只测了DeepSeek的有效性）

研报整合：技术因子与 22 类扩展指标、历史信号验证、策略回测、关联报价、交易查询、资金流向、综合资讯、板块资讯、**法定披露公告**（按股票代码精确采集，分「公司治理/经营事项」与「财报业绩」两组）、基本面/估值、全球关联环境。

**给模型的不是「当前值」**。每个指标还附带：

```text
recent12      最近 12 根轨迹
delta5/20     近 5 / 20 期变化
slope5/20     斜率
percentile60  60 期分位
recentCross   近期交叉
```

所以模型能分析「柱体收缩、斜率减弱、分位过热」，而不是机械复述最新数值。

**平衡型 Prompt 硬约束**：多空证据对等、差异不等于负面、未知/未扫描只降低证据质量而不当作利空、历史胜率不等于未来概率。

**DeepSeek 思考模式**可选 `低(推荐) / 自动 / 关闭 / 高 / 最大`。部分 DeepSeek V4 响应会出现 `reasoning_content` 有内容而 `content` 为空，程序会识别「推理即正文」直接恢复，不浪费第二次调用。

**研报持久化**到 `~/.stockdesk/ai-reports/`，刷新、切股、重启后都能恢复当时的数据快照；支持导出 **Word `.docx`** 与 **PDF**。LLM 原始响应与输入快照完整保存在程序目录的 `llm_raw_outputs/`（**不含 API Key**）。

### LLM 自主外部研究 Agent

不是「预设几条固定搜索词」，而是让模型自己多轮决策：

```text
本地结构化数据
     ↓
LLM 判断：还缺什么外部事实？
     ↓
自主决定：查询词 / 语言 / 来源偏好 / 是否读正文
     ↓
StockDesk 执行搜索 + 安全读网页 → 资料标 R1/R2/R3...
     ↓
LLM 读新增证据，决定：继续 / 换方向 / 停止
     ↓
最终研报
```

三档预算（**上限，不是目标** —— 第一轮就可以判断「证据充分」并停止）：

| 档位 | 轮数 | 查询 | 网页 |
|:--|--:|--:|--:|
| 快速 · 盘中 | ~2 | 4 | 4 |
| 标准 · 推荐 | ~3 | 10 | 12 |
| 深度 · 收盘后 | ~5 | 20 | 28 |

每轮只要求模型给出简短「研究理由」，不要求暴露私有思维链。网页来源标 **A–E 类型先验**（A=一手/官方，B=主流专业媒体，C=行业研究，D=普通财经，E=聚合/百科/社区）——**该等级只提示来源类型，不自动证明内容真实**。

搜索结果与网页正文**始终当作不可信数据**处理（网页里的任何指令都不会被执行），URL 与重定向执行 SSRF / 私网地址防护。完整研究过程写入 `llm_raw_outputs/<本次调用>/research_agent_log.json`。

### 可选本地 AI（默认关闭）

「策略实验室 → 本地 AI 增强」是**可选模块，不是强制依赖**。默认状态为**关闭 / 未安装**，主程序完全没有 Python 也能正常跑。

只有你显式点击安装，才会在 `~/.stockdesk/ai-engine/` 下建独立 venv 并从**上游官方仓库**下载模型：

| 模型 | 定位 | 许可证 |
|:--|:--|:--|
| **Kronos-mini / small / base** | 金融 K 线基础模型，MIT 公开权重 | MIT |
| **MASTER CSI300 / CSI800** | AAAI 2024 横截面排序 | MIT |
| **Qlib TRA** | 市场模式路由，需自行训练 | MIT |
| **River** | 盘中在线概率校准与漂移检测 | BSD-3-Clause |

**影子模式**：AI 只记录和展示 `BUY / WATCH / HOLD / REDUCE / EXIT`，**不影响正式策略监控**。你可以先观察一段时间再决定是否继续实验。

**快慢两层学习**：Kronos 基础权重保持独立，盘中适应交给轻量在线模型 —— 产生预测 → 存 pending label → 标签成熟 → `learn_one` 校准 → 更新概率与漂移状态。**没有未来数据泄漏**，也不会「每来一个 Tick 就重训 Transformer」。

安装前会显示 CPU、逻辑线程、内存、GPU/显存、Python 版本与磁盘剩余空间并给出硬件推荐（Lite → mini / Standard → small / Advanced → base）。

### 数据源管理 · 多源轮换与限速

`设置 → 数据源管理` 提供：

- 三种调度：`自适应轮换（推荐）` / `严格轮换` / `按优先级`；
- 三个缓存档位：`保守` / `平衡（推荐）` / `积极降频`；
- 每个源可单独**启用/关闭、设置优先级、设置源级与能力级最小访问间隔**；
- 查看各源成功率、延迟、错误与熔断状态，可手动**解除熔断**、**测试数据源**；
- **自定义 / 付费 REST Provider（未测试）**：支持 `quote / kline / minute`、GET/POST、字段映射、批量报价与 `{secret}` 密钥占位。密钥由 Electron `safeStorage` 单独保存，不进入普通设置文件。

```json
[{
  "id": "myfeed",
  "label": "我的付费行情",
  "enabled": true,
  "capabilities": ["quote"],
  "minIntervalMs": 5000,
  "quote": {
    "method": "GET",
    "batch": true,
    "url": "https://api.example.com/quotes?symbols={symbols}",
    "headers": {"Authorization": "Bearer {secret}"},
    "root": "data",
    "map": {"code":"code","name":"name","price":"last","prevClose":"prev_close"}
  }
}]
```

> 为避免用旧数据产生错误主动信号，陈旧缓存可以维持界面显示，但**不会触发目标价、策略买点、风险、止损或退出提醒**。

## 🔐 安全与隐私

- **API Key 不落地明文**：Windows 优先用 Electron `safeStorage` 加密；安全存储不可用时**只留在本次运行的内存**里；历史研报与原始输出文件**不含 Key**；
- **渲染进程受 CSP 约束**：`default-src 'self'`、`script-src 'self'`，无 `unsafe-eval`；
- **上下文隔离**：`preload.js` 通过 `contextBridge` 暴露**白名单** API（50 个 IPC 通道），渲染层拿不到 Node；
- **SSRF 防护**：外部研究读取网页前校验 URL 与重定向目标，拦截私网地址；
- **不绕过任何访问控制**：Provider Hub 只做**尊重限流的退避**，403/412/418/429 或典型 WAF 响应立即冷却并持久化；
- **状态目录在用户主目录**：`~/.stockdesk/`，不污染安装目录。
